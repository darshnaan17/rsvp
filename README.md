# Darshan's Prewedding Ceremony RSVP

A private-by-design RSVP experience hosted on GitHub Pages.

- Public site: `index.html`, `styles.css`, `app.js`
- Private backend: `google-apps-script/Code.gs`
- Guest data: private Google Sheet only

Guests enter their name, attendance status, and any additional guests. Party size is calculated automatically. Each response receives a private edit link that remains active through November 11, 2026.
